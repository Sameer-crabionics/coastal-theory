# Coastal Theory

Coastal Theory is a premium seafood discovery and pre-order platform for Odisha, starting with Bhubaneswar and Berhampur.

The MVP is designed to validate demand with almost zero capital by combining Instagram discovery, WhatsApp ordering, fixed-day delivery, and pre-orders sourced only after customer payment.

## MVP Validation Goal

Get the first 20 paying customers without taking inventory risk.
